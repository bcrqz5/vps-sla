## 什么是搬瓦工循环优惠码？

普通一次性优惠码只影响首次付款。例如原价是 100 美元，首次下单减免 10 美元，下一次续费仍然按原价计算。

循环优惠码的逻辑不同：如果优惠码确实被系统设置为 recurring discount，首次订单和之后的续费订单都可能按照相同折扣计算。对长期运行网站、代理服务、开发环境或远程办公服务器的人来说，续费价格往往比首购价格更值得关注。

不过，循环优惠也有几个容易被忽略的限制：

- 不同产品线可能使用不同的优惠规则。
- 某些优惠码只适用于特定计费周期。
- 新套餐、促销套餐或特殊线路可能不接受旧优惠码。
- 优惠码当前能用，不代表之后续费时规则永远不变。
- 订单升级、迁移或更换产品后，原折扣是否保留需要看搬瓦工账户和产品规则。
- 价格变化、产品下架和库存状态都可能影响最终金额。

所以，“循环”描述的是优惠规则，不是对所有未来订单的无条件承诺。
